# 🎂💖 Birthday Surprise Website

A beautiful, animated React website designed for birthday celebrations with a cute, girly, pastel aesthetic.

## ✨ Features

- **Cute & Girly Design**: Soft pastel colors (pink, lavender, baby blue, peach, cream)
- **Smooth Animations**: Powered by Framer Motion with gentle, dreamy transitions
- **Responsive Design**: Works perfectly on mobile, tablet, and desktop
- **5 Unique Message Sections**: Each with different cute styles and animations
- **Interactive Photo Gallery**: Polaroid-style photos with hover effects
- **Floating Elements**: Hearts, stars, balloons, and confetti animations

## 🎨 Design Elements

- **Typography**: Quicksand, Comfortaa, Poppins, and Caveat fonts
- **Colors**: Pastel pink, lavender, baby blue, peach, and cream
- **Animations**: Floating, bouncing, scaling, and rotating effects
- **Decorative Elements**: Cake, balloons, ribbons, confetti, sparkles, hearts, stars

## 🛠 Tech Stack

- React 19
- JavaScript
- Framer Motion
- Tailwind CSS
- Vite

## 📝 Content Placeholders

Replace these placeholders with your personalized content:

- `{{HER_NAME}}` - Birthday person's name
- `{{PARA_1}}` to `{{PARA_5}}` - Message paragraphs
- `{{FINAL_MESSAGE}}` - Final thank you message
- `{{IMG_1}}` to `{{IMG_12}}` - Photo gallery images

## 🚀 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## 📱 Sections

1. **Hero Section**: Main birthday greeting with floating decorations
2. **Message Sections**: 5 uniquely styled message cards
3. **Photo Gallery**: Interactive polaroid-style photo grid
4. **Final Section**: Thank you message with replay button
